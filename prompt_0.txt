# Efficient LLM Collaboration Inference

## 项目简介

Efficient LLM Collaboration Inference是一个高效的大语言模型协作推理系统，旨在优化多模型协同工作的流程。该系统通过任务分解、并行处理和模型协作，实现了高效的问题解决方案，特别适用于复杂问题的处理。

### 核心特点

- **任务自动分解**：使用路由模型将复杂问题分解为多个子任务，形成有向无环图(DAG)的工作流
- **动态模型分配**：基于任务难度自动选择合适的模型（小模型或大模型）
- **并行任务处理**：支持多线程并行执行独立子任务，提高整体处理效率
- **性能监测与分析**：提供详细的性能指标，包括响应时间、Token使用量和成本估算
- **数据集批量处理**：支持对数据集进行批量处理和评估

### 工作原理

系统工作流程如下：

1. 路由模型接收问题并生成任务计划（包含多个子任务及其依赖关系）
2. 系统分析每个子任务的难度，为其分配合适的模型（小模型或大模型）
3. 调度器根据任务依赖关系并行执行任务
4. 系统整合各子任务结果，生成最终答案
5. 生成性能报告和任务依赖分析
