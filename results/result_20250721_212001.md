# 问题求解最终结果

## 原始问题
Find the number of ordered pairs $(a,b)$ of integers such that $|a + bi| \le 5.$

## 解决步骤

### 步骤 1: Recognize that |a + bi| ≤ 5 represents points in the complex plane within a circle of radius 5 centered at origin
Radius \( \leq 5 \) implies integer points \((a, b)\) form a grid.

### 步骤 2: Convert complex modulus inequality to its geometric form: a² + b² ≤ 25
a² + b² ≤ 25

### 步骤 3: Identify that we need to count integer coordinates (a,b) inside or on this circle
Count integer solutions for \( a^2 + b^2 \leq 25 \).

### 步骤 4: Utilize symmetry - circle is symmetric about both axes, so count in one quadrant and multiply
Count integer solutions for \(a \geq 0\) and \(b \geq 0\).

### 步骤 5: Count integer points systematically: for each row/column within radius 5, including boundary
Count \((a, b)\) points for each \(a\), \(a^2 + b^2 \leq 25\).

### 步骤 6: Apply symmetry multiplication (×4 for quadrants + points on axes) to get final count
Multiply solutions by 4 to account for all quadrants and add axis points.

## 最终答案
81
