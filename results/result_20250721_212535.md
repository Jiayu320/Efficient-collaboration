# 问题求解最终结果

## 原始问题
Find the domain of $\sqrt{6-x-x^2}$.

## 解决步骤

### 步骤 1: Recognize this is a square root expression requiring non-negative values under the radical
Set \(6-x-x^2 \geq 0\).

### 步骤 2: Set up inequality: 6-x-x^2 ≥ 0
\(6 - x - x^2 \geq 0\)

### 步骤 3: Rearrange to standard quadratic form: x^2 + x - 6 ≤ 0
x² + x - 6 ≤ 0

### 步骤 4: Find roots of x^2 + x - 6 = 0 using quadratic formula
\(x = \frac{{-b \pm \sqrt{{b^2 - 4ac}}}}{2a}\), with \(a=1, b=1, c=-6\).

### 步骤 5: Determine that roots are x = -3 and x = 2
Solve \((x + 3)(x - 2) = 0\).

### 步骤 6: Analyze parabola opens upward (positive x^2 coefficient) to identify interval where expression is negative
For \(x^2 + x - 6 < 0\): interval is \((-3, 2)\).

### 步骤 7: Conclude domain is [-3, 2] since quadratic is ≤ 0 between its roots
The quadratic is ≤ 0 in \([-3, 2]\).

## 最终答案
[-3, 2]


## 答案正确性判断

标准答案: First, we simplify the expression: $$\sqrt{6-x-x^2}=\sqrt{(2-x)(3+x)}$$ The expression inside the square root must be non-negative. The quadratic changes signs at the roots $2$ and $-3$ and is positive between the two values. Therefore, the domain of the expression is $\boxed{[-3,2]}$.

判断结果: 答案正确
