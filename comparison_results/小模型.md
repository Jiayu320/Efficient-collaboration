## 原始问题
Find the last three digits of the product of the positive roots of $\sqrt{1995}x^{\log_{1995}x}=x^2.$

## 解决方案
To solve the equation \(\sqrt{1995} x^{\log_{1995} x} = x^2\), we start by taking the logarithm base 1995 of both sides. The equation becomes:

\[
\log_{1995} (\sqrt{1995} x^{\log_{1995} x}) = \log_{1995} (x^2).
\]

Using the properties of logarithms, this can be rewritten as:

\[
\log_{1995} \sqrt{1995} + \log_{1995} x^{\log_{1995} x} = 2 \log_{1995} x.
\]

Next, we simplify each term. Note that \(\log_{1995} \sqrt{1995} = \log_{1995} (1995^{1/2}) = \frac{1}{2}\). Also, \(\log_{1995} x^{\log_{1995} x} = (\log_{1995} x) \cdot (\log_{1995} x) = (\log_{1995} x)^2\). So the equation becomes:

\[
\frac{1}{2} + (\log_{1995} x)^2 = 2 \log_{1995} x.
\]

Let \(y = \log_{1995} x\). Then the equation simplifies to:

\[
\frac{1}{2} + y^2 = 2y.
\]

Rearranging terms, we get a standard quadratic equation:

\[
y^2 - 2y + \frac{1}{2} = 0.
\]

To solve this quadratic equation, we use the quadratic formula \(y = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}\), where \(a = 1\), \(b = -2\), and \(c = \frac{1}{2}\). Plugging in these values, we get:

\[
y = \frac{2 \pm \sqrt{4 - 2}}{2} = \frac{2 \pm \sqrt{2}}{2} = 1 \pm \frac{\sqrt{2}}{2}.
\]

Therefore, the solutions are:

\[
y = 1 + \frac{\sqrt{2}}{2} \quad \text{and} \quad y = 1 - \frac{\sqrt{2}}{2}.
\]

Converting these back to \(x\), we have:

\[
x = 1995^{1 + \frac{\sqrt{2}}{2}} \quad \text{and} \quad x = 1995^{1 - \frac{\sqrt{2}}{2}}.
\]

We need to find the last three digits of the product of these roots. The product of the roots is:

\[
1995^{1 + \frac{\sqrt{2}}{2}} \cdot 1995^{1 - \frac{\sqrt{2}}{2}} = 1995^{(1 + \frac{\sqrt{2}}{2}) + (1 - \frac{\sqrt{2}}{2})} = 1995^2.
\]

Now, we need to find the last three digits of \(1995^2\). First, we compute \(1995^2 \mod 1000\):

\[
1995^2 = (2000 - 5)^2 = 2000^2 - 2 \cdot 2000 \cdot 5 + 5^2 = 4000000 - 20000 + 25 = 3980025.
\]

Taking the last three digits of 3980025, we get 025. Therefore, the last three digits of the product of the positive roots are:

\[
\boxed{025}.
\]
